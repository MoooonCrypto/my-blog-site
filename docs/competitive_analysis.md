# Positioning

このサイトはブログサービスや一般的なCMSを作り直すことが目的ではありません。転職活動で見てもらう制作物を、自分の文脈で整理して提示するための小さなポートフォリオCMSです。

## Alternatives

| Alternative | Good at | Why this project exists |
|---|---|---|
| GitHub profile README | リポジトリ一覧や活動履歴を見せやすい | プロダクトごとの説明、画像、デモ導線を整理しにくい |
| Notion / note | 文章を素早く公開しやすい | 実装力やUI設計をコードとして見せにくい |
| Medium / Hashnode / DEV.to | 技術記事の公開に強い | プロダクト一覧、プロフィール、管理画面を一体化しにくい |
| Static portfolio template | 公開までが速い | 掲載内容を更新するたびにコード変更が必要になりやすい |

## Design Goals

- 採用担当者が短時間で制作物に辿り着けること
- 開発者がリポジトリを見たときに、構成と責務を追いやすいこと
- 掲載内容を管理画面から更新できること
- 未完成の機能を完成済みのように見せないこと
- 個人開発として運用しやすいサイズに保つこと

## Non-Goals

- 汎用CMS化
- 一般ユーザー向けアカウント機能
- 記事投稿プラットフォーム化
- 大規模な権限管理
