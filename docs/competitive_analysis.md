
# 競合分析表

## 競合サービス

| サービス名 | 主要機能 | 価格帯 | ターゲット層 | 競合の弱点・ペインポイント |
|---|---|---|---|---|
| **個人開発者のポートフォリオサイト** | - プロジェクト紹介<br>- 自己紹介<br>- スキル一覧<br>- ブログ | 無料 | 開発者、デザイナー | - 集客力がない<br>- ブログ機能が弱い<br>- SEO対策が不十分 |
| **Hashnode** | - ブログ機能<br>- カスタムドメイン<br>- Markdown対応<br>- GitHub連携<br>- ニュースレター機能 | 無料 | 開発者 | - ポートフォリオ機能がない<br>- デザインの自由度が低い |
| **Medium** | - ブログ機能<br>- 収益化機能<br>- 多くの読者 | 無料 | 一般のライター、開発者 | - カスタムドメインが有料<br>- 広告が表示される<br>- ポートフォリオ機能がない |
| **DEV.to** | - ブログ機能<br>- コミュニティ機能<br>- Markdown対応 | 無料 | 開発者 | - ポートフォリオ機能がない<br>- デザインの自由度が低い |
| **WordPress** | - ブログ機能<br>- 豊富なテーマとプラグイン<br>- 高いカスタマイズ性 | 無料（ホスティング費用は別途） | ブロガー、企業 | - 開発者向けの機能が少ない<br>- セットアップが複雑 |

## 必須機能と差別化ポイント

### 必須機能

- プロジェクト紹介
- 自己紹介
- スキル一覧
- ブログ機能
- お問い合わせフォーム

### 差別化ポイント

- **ポートフォリオとブログの統合:** 開発者向けのポートフォリオ機能とブログ機能をシームレスに統合し、1つのプラットフォームで完結できるようにする。
- **デザインの自由度:** Tailwind CSSをベースに、シンプルでカスタマイズ性の高いデザインテンプレートを提供する。
- **シンプルな管理画面:** コンテンツの追加・編集が直感的に行える、分かりやすい管理画面を用意する。
- **SEO対策:** Next.jsのSSG/SSRを活用し、SEOに強いサイト構造を実現する。
- **開発者体験:** Markdownでの記事執筆、GitHub連携による記事管理など、開発者にとって使いやすい機能を提供する。
