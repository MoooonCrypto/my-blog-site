# タスク完了時のチェックリスト

## コード変更後の確認事項

### 1. リント・型チェック
```bash
npm run lint
```
- ESLintエラーがないことを確認
- TypeScriptの型エラーがないことを確認

### 2. ビルドテスト
```bash
npm run build
```
- ビルドが正常に完了することを確認
- 警告やエラーがないことを確認

### 3. 開発サーバーでの動作確認
```bash
npm run dev
```
- 変更箇所が期待通りに動作することを確認
- 関連するページやコンポーネントが壊れていないことを確認

## 認証関連の変更の場合

### 追加の確認事項
- [ ] `/admin/login` でログインできるか
- [ ] `/admin/*` ページが適切に保護されているか
- [ ] ログアウト機能が正常に動作するか
- [ ] リダイレクトが正しく機能するか

## UIコンポーネント変更の場合

### 追加の確認事項
- [ ] ダークモードで正常に表示されるか
- [ ] レスポンシブデザインが維持されているか
- [ ] アクセシビリティが損なわれていないか

## Git コミット前

### コミット前の確認
- [ ] 不要なファイルが含まれていないか（`git status`で確認）
- [ ] `.env`ファイルなど、機密情報が含まれていないか
- [ ] コミットメッセージは日本語で適切に記述されているか
  - 形式: `feat:`, `fix:`, `refactor:`, `docs:` など

### コミットメッセージの例
```
feat: ブログ記事の検索機能を追加
fix: ログインページのバリデーションエラーを修正
refactor: 認証ロジックをSupabaseへ移行
docs: READMEに環境変数の説明を追加
```

## プルリクエスト作成時

### 確認事項
- [ ] ブランチが最新のmain/masterから作成されているか
- [ ] コンフリクトがないか
- [ ] 変更内容が明確に説明されているか
- [ ] レビュアーに必要な情報を提供しているか

## デプロイ前（Vercel）

### 確認事項
- [ ] 環境変数がVercelに正しく設定されているか
- [ ] ビルドが成功するか
- [ ] プレビューデプロイで動作確認ができているか
